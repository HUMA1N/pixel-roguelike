# pixel-roguelike — «Пиксельный выживальщик»

Браузерная аркада-выживание в духе Vampire Survivors. Герой стоит в центре арены, враги
идут со всех сторон, а герой стреляет сам. Ваша задача — двигаться, уворачиваться
и собирать кристаллы опыта. На каждом новом уровне вы выбираете одно из трёх улучшений.

Игра написана на чистом JavaScript и Canvas: без библиотек, без сборки и без картинок.
Вся графика (пиксельные спрайты, эффекты) рисуется кодом.

**Играть онлайн:** https://huma1n.github.io/pixel-roguelike/ (ссылка заработает, когда
будет включена публикация на GitHub Pages — см. ниже).

## Управление

| Где | Как |
| --- | --- |
| Компьютер | Стрелки или **W A S D** — движение, **Esc** или **P** — пауза, **1 2 3** — выбор улучшения, **Enter** — начать |
| Телефон | Коснитесь экрана и ведите пальцем — появится джойстик. Улучшение выбирается касанием |

Стреляет герой сам — целиться не нужно.

## Что есть в игре

- **Враги:** слизни, летучие мыши (быстрые, летят зигзагом), големы (медленные и крепкие),
  колдуны (держатся на расстоянии и стреляют). Каждые 3 минуты приходит босс — **Король
  слизней**, а время от времени враги окружают героя кольцом.
- **Оружие:** магический жезл, кружащие клинки, морозная аура, молния.
- **Пассивные улучшения:** сила, скорострельность, сапоги, живучесть, регенерация, магнит,
  броня, пробивание, размах.
- **Предметы:** сердце лечит, магнит притягивает все кристаллы на карте.
- **Рекорд** (лучшее время, больше всего убитых, самый высокий уровень) хранится в браузере
  (`localStorage`) и не пропадает после перезагрузки страницы.
- Простые звуки, синтезированные прямо в браузере. Выключить их можно в меню паузы.

## Как запустить на Windows (для новичка)

### Способ 1 — самый простой, ничего не устанавливая

1. На странице репозитория на GitHub нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Найдите скачанный архив в папке «Загрузки», нажмите на него правой кнопкой мыши →
   **Извлечь всё…** → **Извлечь**.
3. Откройте распакованную папку и дважды щёлкните по файлу **`index.html`**.
   Игра откроется в браузере (Chrome, Edge, Firefox — любой современный).

### Способ 2 — через локальный сервер (если нужен адрес вида http://localhost)

1. Установите Node.js с сайта https://nodejs.org (кнопка «LTS», дальше «Далее»→«Далее»).
2. Откройте папку с игрой в Проводнике, щёлкните по адресной строке, напишите `cmd`
   и нажмите Enter — откроется командная строка уже в этой папке.
3. Введите `npm start` и нажмите Enter (при первом запуске небольшой сервер скачается
   автоматически). Чтобы остановить сервер, нажмите `Ctrl + C`.
4. Откройте в браузере адрес http://localhost:8080

### Тесты

Нужен установленный Node.js (см. способ 2). В командной строке в папке игры:

```
npm test
```

Тесты проверяют логику игры: движение, стрельбу, опыт и уровни, выбор улучшений,
появление врагов и босса, сохранение рекорда.

## Публикация на GitHub Pages

В репозитории уже есть файл `.github/workflows/pages.yml`. При каждом обновлении ветки
`main` он запускает тесты и, если они прошли, публикует игру.

Нужно один раз включить настройку: **Settings → Pages → Build and deployment → Source:
GitHub Actions**. После этого игра будет доступна по адресу
https://huma1n.github.io/pixel-roguelike/

## Устройство кода

```
index.html        страница и экраны меню
css/style.css     оформление меню и карточек улучшений
js/utils.js       математика, случайные числа, сохранение рекорда
js/enemies.js     виды врагов и правила их появления
js/upgrades.js    оружие и улучшения, выбор 1 из 3
js/game.js        игровая логика (без браузера — её проверяют тесты)
js/sprites.js     пиксельные спрайты, записанные строками символов
js/render.js      отрисовка на Canvas
js/input.js       клавиатура и сенсорный джойстик
js/audio.js       звуки через Web Audio
js/main.js        игровой цикл, экраны, пауза
tests/            тесты (node:test)
```

Файлы подключаются обычными тегами `<script>`, а не модулями, поэтому игра работает даже
при открытии `index.html` двойным щелчком.
